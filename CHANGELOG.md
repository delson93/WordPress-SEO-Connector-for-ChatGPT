# Changelog

## 0.2.0 - 2026-10-20

- Private Custom GPT Actions schema, dedicated hashed Bearer key, rotation and revocation.
- Explicit administrator field authorization for remote apply/rollback, exact proposal digest and creator checks.
- Yoast 28.7 title/description/social output overrides via documented filters, preserving protected metadata and tag ownership.
- Effective metadata reads and updated setup instructions. Direct attachment to an existing chat and OAuth MCP remain unsupported.
- Expanded security tests and real Yoast integration tests.

## 0.1.0 - 2026-10-20

Initial MVP: authenticated audits, native administration, REST API, optional WordPress MCP abilities, bounded public HTML checks, administrator-approved proposals, snapshot history, conflict-aware rollback, metadata fallback and audit exports. Includes build automation and tests. No OAuth server, automatic third-party SEO writes or unattended full-site repair.
